# Glossary

| Term | Meaning |
| --- | --- |
| Proof of Intent | Verifiable binding between owner objective, policy and proposed action; signed binding is planned |
| Pawprint Receipt | Local structured audit record of a verdict |
| Nine Lives | Checkpoint-based recovery design; website version is a lab demo |
| Quarantine | Distrust the surrounding state/context, not just one transaction |
| State Root | Digest of an owner-approved persistent-state baseline |
| Intent Drift | Proposal deviates from the owner's objective |
| Memory Drift | Persistent agent state differs from trusted baseline |
| Program ID | Solana address identifying an executable program |
| Account Meta | Instruction account address with signer/writable flags |
| Writable Account | Account whose data or lamports an instruction may change |
| Simulation Gate | Advisory preflight check before a verdict |
| Reasoning Plane | Model/tool context that creates proposals but has no final authority |
| Authorization Plane | Independent policy/state/transaction checks before wallet review |
