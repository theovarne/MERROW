# Reference examples

These small Node programs exercise repository reference modules. They are not a released SDK or signing CLI.

Run from the repository root after `npm ci`:

```sh
node examples/compile-policy.mjs
node examples/quarantine-flow.mjs
```

The website's serialized Solana transaction parser remains in `website/index.html`. It is a browser prototype; a reusable, audited parser is not yet published here.
