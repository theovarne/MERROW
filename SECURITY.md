# Security Policy

Merrow is experimental software. The website and reference modules are not an audited or production-grade wallet protection system.

Do **not** post private keys, seed phrases, wallet secret material, API keys, RPC credentials or access tokens in public issues, pull requests, screenshots or logs. If GitHub Private Vulnerability Reporting is enabled for this repository, use that channel for sensitive vulnerability details. No private security email is currently published; do not assume a public issue is confidential.

For a public, non-sensitive bug, open an issue with reproducible steps, affected commit and expected versus observed behavior. Please redact transaction or account data you do not have permission to disclose. Do not include live exploit instructions against third parties.

Supported target for reports: the current `main` branch. No stable release or security-support window is promised.
